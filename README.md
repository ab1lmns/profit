# Отбор в спецгруппу — MVP

Лендинг + личный кабинет ученика с тестированием + админ-панель преподавателя.
Направления тестирования: HTML/CSS, JavaScript, Python, C#, английский язык (CEFR).

Стек: **React + Vite + Tailwind CSS**, иконки — `lucide-react`.
Бэкенда и базы пока нет — все данные хранятся в `localStorage` браузера
(см. `src/lib/storage.js`), это временная замена, пока не подключён
реальный сервер и MongoDB.

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

Сборка для продакшена:

```bash
npm run build
npm run preview
```

## Структура проекта

```
index.html                  входная HTML-страница (шрифты подключены тут)
src/
  main.jsx                  точка входа React
  App.jsx                   маршрутизация между экранами (state-based, без react-router)
  index.css                 подключение Tailwind
  data/
    tracks.js                метаданные 5 направлений + цветовые токены
    questions.js              банки вопросов + логика подсчёта уровня/CEFR
  lib/
    storage.js                 слой хранения данных (localStorage). Именно тут
                                нужно будет заменить localStorage на fetch()
                                к вашему API, когда появится бэкенд/MongoDB
  components/
    ui.jsx                     мелкие переиспользуемые элементы (кнопки, бейдж уровня)
    Landing.jsx                лендинг
    StudentAuth.jsx             регистрация/вход ученика
    StudentDashboard.jsx        личный кабинет ученика со списком треков
    TestRunner.jsx              прохождение теста + экран результата
    AdminLogin.jsx               вход преподавателя (пока условный, без проверки)
    AdminDashboard.jsx           панель преподавателя: Обзор / Ученики / Направления / Настройки
```

## Что уже работает

- Регистрация ученика (имя, email, класс), повторный вход по email.
- 5 тестов с автоматическим подсчётом результата:
  - HTML/CSS, JS, Python, C# → уровень «Начальный / Средний / Продвинутый»
    (взвешенно по сложности вопросов).
  - Английский → уровень по шкале **CEFR (A1–C2)** по количеству верных ответов.
- Личный кабинет ученика со статусом по каждому направлению.
- Кабинет преподавателя:
  - **Обзор** — счётчики и распределение уровней по направлениям.
  - **Ученики** — таблица с поиском и карточкой результатов по клику.
  - **Направления** — список банков вопросов (редактирование — заглушка).
  - **Настройки** — пояснение про хранилище + кнопка очистки демо-данных.

## Дальнейшие шаги (когда будет бэкенд)

1. Поднять API (Node/Express, Fastify — на ваш выбор) с MongoDB.
2. В `src/lib/storage.js` заменить тела функций `loadStudents`,
   `saveStudent`, `deleteStudent`, `clearAllStudents`, `loadSession`,
   `saveSession`, `clearSession` на запросы `fetch(...)` к API —
   сигнатуры функций менять не нужно, компоненты их не заметят.
2. Добавить настоящую авторизацию преподавателя (сейчас — заглушка).
3. Расширить банки вопросов в `src/data/questions.js` и, при желании,
   вынести их в базу, чтобы преподаватель мог редактировать вопросы
   из вкладки «Направления».
4. Добавить таймер на прохождение теста, если нужно ограничение по времени.
